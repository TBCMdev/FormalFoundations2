# Formal Foundations 2 Proofs - UCD Computer Science (Stage 2)

Here is most of the proofs for Formal Foundations 2 we've been asked to prove.
> Github doesn't render these correctly! Use an IDE
> Some proofs are not here as the proof after demonstrates a similar method, or I was too lazy (like 60).

## Contributing

If you have a proof you want to add just clone the repo yourself and write it up in markdown, then send a push/merge request.

## Notes

- 'lhs': Left hand side of equation
- 'rhs': Right hand side of equation
- 'F': Shorthand for `false` (looks more neat)
- 'T': Shorthand for `true`  (looks more neat)

- The github app doesn't render math markdown or markdown.
