# $[x \not\equiv F \equiv x]$

> Note F is false

We observe for any $x$:
- Starting with the lhs $x \not\equiv F$, we remove the not equiv **asap** and use **(36)** to get a double negation:
    ```math
    x \not\equiv F
    \\ \rightarrow \\
    \neg(x \equiv F) ~~~~ \{\bold{(36)}\}
    \\ \rightarrow \\
    \neg (\neg x) \rightarrow x   
    ```
