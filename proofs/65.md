# $[x \land (y \not\equiv z) \equiv x \land y \not\equiv x \land z]$

We observe for any $x, y ,z$:

- Starting with the **most lhs** term, we get rid of the not equiv **asap**:
    $$x \land (y \not\equiv z) \rightarrow x \land \neg(y \equiv z)$$
- Then lets bring the **$\neg$** inside the brackets using , as then we will have the form of **(35)** : **$a \land (b \equiv c)$**:
    $$x \land \neg(y \equiv z)$$
    $$x \land (\neg y \equiv z)$$
 
- Now we can see that we have the form of **(35)** with $x, y, z := x, \neg y, z$ :
    ```math
    x \land (\neg y \equiv z)
    \\ \rightarrow \\
    x \land \neg y \equiv x \land z \equiv x
    ```
- If we swap **$x \land \neg y \rightarrow y \land \neg x$**, then we have the form of **(44)**:

    ```math
    x \land \neg y
    \\ \rightarrow \\
    y \land \neg x
    \\ \rightarrow \{\bold{(44)}\} \\
    y \land x \equiv \neg x

    ```
    So we have:
    ```math
    y \land x \equiv \neg x \equiv x \land z \equiv x
    ```

- Next, we can see that we have **$\neg x \equiv x$**, which we can replace with **$F$ (false)** using **negative identity (36)**:
    ```math
    y \land x \equiv F \equiv x \land z 
    ```
- Now this is the trickiest to see, but we can use this **$F$ (false)** again to replace either the **$y \land x$ or $x \land z$** using **(36) (x2)**. Lets replace **$x \land z$**:
    ```math
    y \land x \equiv F \equiv x \land z
    \\ \rightarrow \\
    y \land x \equiv \neg(x \land z)
    \\ \rightarrow \\
    x \land y \not\equiv x \land z    
    ```
