# $[x \land y \equiv y \land x]$

We observe for any $x, y$:

- Starting with lhs, using **Golden Rule (11)**:
    $$x \land y \rightarrow x \equiv y \equiv x \lor y$$
- Then with **Symmetry (1)**:   
    $$y \equiv x \equiv x \lor y$$ $$y \equiv x \equiv y \lor x$$

- Then with **Golden Rule (11)** with **$x,y:= y,x$**:
    $$\rightarrow y \land x$$
