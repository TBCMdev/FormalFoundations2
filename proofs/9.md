# $[x \lor (y \lor z) \equiv (x \lor y) \lor (x \lor z)]$
We observe for any $x, y, z$:

- Starting with the lhs $x \lor (y \lor z)$, using **Idempotency (7)**:
    $$x \lor x \lor (y \lor z) = 
    x \lor x \lor y \lor z$$
- Then using **Symmetry (5)**:
    $$x \lor y \lor x \lor z$$
    $=$
    $$(x \lor y) \lor (x \lor z)$$
