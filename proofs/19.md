# $[x \land (y \lor z) \equiv (x \land y) \lor (x \land z)]$


We observe for any $x, y , z$:

- We start with the rhs and use the previous law **$\lor/\land$ (18)** with **$x, y, z := (x \land y), x, z$**:

    $$(x \land y) \lor (x \land z) \rightarrow ((x \land y) \lor x) \land ((x \land y) \lor z)$$

- Using **symmetry (5)**, we can swap around the lhs:

    $$(x \land y) \lor x \rightarrow x \lor (x \land y)$$

- Which has the form of the **Absorption1 (17)** law:

    $$x \lor (x \land y) \rightarrow x$$

    So we have:

    $$x \land ((x \land y) \lor z)$$

- We can use **$\lor/\land$ (18)** again with **$x, y, z := z, y, x$**:

    $$(x \land y) \lor z \rightarrow z \lor (x \land y)$$ $$\rightarrow$$

    $$(z \lor x) \land (z \lor y)$$

    So we have:
    $$x \land ((z \lor x) \land (z \lor y))$$

- Finally since we have two and operations, we can move the brackets using **associativity (6)**:

    $$x \land ((z \lor x) \land (z \lor y)) \rightarrow (x \land (z \lor x)) \land (z \lor y)$$
    
    $$\rightarrow$$

    $$(x \land (x \lor z)) \land (z \lor y)$$

- Finally, since **$(x \land (x \lor z))$** is in the form of **absorption0 (16)**:

    $$(x \land (x \lor z))\rightarrow x$$

    $$\therefore (x \land (x \lor z)) \land (z \lor y) \rightarrow x \land (y \lor z) $$
